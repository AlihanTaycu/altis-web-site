# Altis Motion

Remotion workspace for generating Altis website loops and social media videos.

## Commands

- `npm run video:studio` from the repository root opens Remotion Studio.
- `npm run video:render:web` renders the TrueScan web loop to `public/videos/truescan-web-loop.mp4`.
- `npm run video:render:social` renders the TrueScan portrait social video to `public/videos/truescan-social-portrait.mp4`.

The TrueScan web loop is an ambient, text-free motion visual. The social composition is a
separate portrait video with copy. Both mirror the site asset from
`public/images/truescan/truescan-marketing.png` to
`remotion/public/images/truescan/truescan-marketing.png` so Remotion can serve it during Studio
previews and renders.
